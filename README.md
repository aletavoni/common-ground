# Common Ground

A classroom game about private protection, public goods and Nash equilibrium. Play against three bots following one of two fixed Nash equilibrium profiles.

This is an independent teaching adaptation of the private–public goods game in Malthouse et al. (2026), *The private solution trap in collective action problems across 34 nations*, PNAS 123, e2504632123. [Read the paper](https://doi.org/10.1073/pnas.2504632123).

## Play

The game is contained in `index.html`. It runs entirely in your browser with no installation, sign-in or server-side code. A game lasts ten rounds. The guide and results explain the rules and equilibrium incentives.

Choices remain in browser memory and reset on refresh. CSV exports are generated locally. The app has no analytics or external runtime dependencies; the hosting provider may keep ordinary access logs.

## Publish with GitHub Pages

In the repository's Settings → Pages, select **Deploy from a branch**, then **main** and **/ (root)**. Save and wait for the deployment to finish. Use the live URL shown on that page to share the game.

Only the generated teaching app is included here. The research PDF and local workspace are not part of this website.
